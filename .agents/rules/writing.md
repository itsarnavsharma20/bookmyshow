# Writing rules

Applies to all Markdown and text files in this repo.

- Write in English.
- Keep sentences short. Use plain words.
- Prefer bullets and tables over long paragraphs.
- Do not use em-dashes. Use a comma or a period.
- Leave a blank line between sections.
- Start each file with a single `#` title.

**Why:** The repo is for learning. Short, plain notes are easier to revise later.

**How to apply:** Check every new or edited doc against this list before finishing.
